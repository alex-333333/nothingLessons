# Уроки — виджет расписания

Виджет для рабочего стола Android в стиле Nothing: показывает, какой урок идёт сейчас,
сколько минут до звонка и какой урок следующий. На перемене — что будет дальше и через сколько,
после уроков — первый урок следующего учебного дня.

Расписание звонков и предметов задаётся один раз в настройках приложения. Виджет обновляется
сам каждую минуту, пока идут уроки, и не тратит батарею, когда экран выключен.

## Установка

1. На телефоне откройте страницу репозитория → **Releases** → **Последняя сборка** (тег `latest`)
   и скачайте `nothing-lessons.apk`.
2. Откройте скачанный файл. Если Android спросит, разрешите установку из неизвестных источников
   для браузера или файлового менеджера.
3. Долгое нажатие на рабочем столе → **Виджеты** → найдите **«Уроки»** и перетащите на экран.
   Виджет появится размером 2×2; его можно растянуть до 4×2.
4. Нажмите на виджет — откроются настройки, где задаются звонки и предметы.

Новые версии ставятся так же, поверх старой: настройки сохраняются.

## Сборка

Нужны JDK 17 и Android SDK (проще всего — через Android Studio).

```sh
./gradlew :app:assembleRelease
# APK: app/build/outputs/apk/release/app-release.apk
```

Тесты логики расписания (чистый Kotlin, Android SDK не нужен):

```sh
./gradlew -p core test
```

Каждый push в `main` собирается в GitHub Actions, и APK выкладывается в релиз `latest`.

## Про ключ подписи

Файл `app/signing.keystore` (пароль `lessons`) лежит в репозитории специально: и локальные сборки,
и сборки в GitHub Actions подписаны одним ключом, поэтому обновление устанавливается поверх
старой версии без удаления. Для личного приложения это нормально, но ключ публичный —
не устанавливайте APK с этим приложением, полученные от посторонних: подписать их может кто угодно.
